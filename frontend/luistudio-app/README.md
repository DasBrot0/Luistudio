# Luistudio frontend

Aplicación React/Vite para estudiantes y administradores de Luistudio. La guía funcional y de configuración completa está en [README_FRONTEND.md](../README_FRONTEND.md).

## Requisitos

- Node.js 22.
- pnpm 10.13.1.

## Comandos

```bash
pnpm install --frozen-lockfile
pnpm run dev
pnpm test
pnpm run build
```

El proyecto usa `pnpm-lock.yaml`; no se deben generar lockfiles de npm o Yarn.
